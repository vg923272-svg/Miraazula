# Mira Azul — Samsung / Free Fire

Projeto Android nativo em Kotlin + Jetpack Compose, com painel gamer azul.

## O que faz
- Organiza valores sugeridos de sensibilidade para o usuário ajustar manualmente no Free Fire.
- Abre as configurações padrão do Android e de bateria.
- Exibe recomendações simples para reduzir aquecimento e quedas de desempenho.

## O que NÃO faz
- Não altera arquivos, memória ou processos do Free Fire.
- Não injeta código, não usa macros, automação de toque, mira automática ou sobreposição.
- Não modifica DPI, taxa de toque, FPS ou configurações protegidas.
- Não garante ausência de banimento; use apenas recursos permitidos pelo jogo.

## Abrir e compilar
1. Extraia o ZIP.
2. Abra a pasta `MiraAzulSamsung` no Android Studio (versão recente).
3. Aguarde a sincronização do Gradle.
4. Selecione um dispositivo/emulador Android 8.0 ou superior.
5. Use **Build > Build APK(s)** para gerar o APK de teste.

Compile com JDK 17 e Android SDK 35 instalado.
